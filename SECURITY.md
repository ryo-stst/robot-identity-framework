# Security policy

## Supported versions

The repository is experimental alpha software. No version is approved for production security use.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature for this repository. Do not open a public issue containing exploit details, private keys, credentials, personal data, or a working proof of concept.

Include the affected revision, impact, reproduction steps, and any suggested mitigation. Receipt or response-time guarantees are not yet offered.

## Security claims

A passing test suite demonstrates only the documented reference behavior. It is not a cryptographic audit, safety certification, identity assurance level, or proof of resistance to relay, side-channel, radio, supply-chain, or physical attacks.
